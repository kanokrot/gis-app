Data interpretation

Category 1 is treated as population matching the mapped access area; -1 is treated as no match. The catalog has no field dictionary, so confirm this interpretation with the publisher.

The 500 m file is labelled for bus stops. The 400 m and 1,000 m summaries use separate public transport layers, so this is not a controlled distance-only comparison.

Halo colour is the access value of the district containing each station, not a measured station catchment.

Catalog updated 11 November 2024; the population reference year is not stated. These are district totals, not household-level results or individual routes.
